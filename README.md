# Electric Vehicle Data Analysis Dashboard (1997-2024)

This repository contains an interactive Power BI dashboard for analyzing electric vehicle (EV) data, showcasing insights into vehicle distribution, market trends, and Clean Alternative Fuel Vehicle (CAFV) eligibility. The project provides comprehensive visualization and analysis of the EV population, catering to policymakers, manufacturers, and EV enthusiasts.

---

## Dashboard Overview

### Key Metrics Displayed
- **Total EV Count**: Number of electric vehicles analyzed.
- **Average Range**: Average electric range of vehicles.
- **Total Base Manufacturer Suggested Retail Price (MSRP)**: Summed MSRP across all vehicles.
- **CAFV Eligibility**: Count of vehicles eligible and not eligible under the Clean Alternative Fuel Vehicle program.

### Key Insights
1. **Total Vehicle Count by Model Year**: Trends in EV registrations over time.
2. **Total Vehicle Count by Make and Model**: Highlights popular EV manufacturers and models.
3. **Total Vehicle Count by Electric Vehicle Type**: Distribution of battery electric vehicles (BEVs) vs. plug-in hybrid electric vehicles (PHEVs).
4. **CAFV Eligibility Distribution**: Proportion of eligible vehicles.
5. **Geographic Distribution of EVs**: Mapping of vehicle registrations across states.
6. **EV Registrations per Year**: Trends in new registrations.
7. **Sum of MSRP by Electric Range**: Correlation of vehicle pricing with range.

---

## Technologies Used
- **Power BI**: Interactive dashboard creation.
- **DAX (Data Analysis Expressions)**: Custom measures for in-depth analysis.
- **Python/Excel** *(optional)*: Pre-processing of raw data before loading into Power BI.
